# 왕궁농협 하나로마트 근무표

Vite, React, Express, SQLite로 만든 왕궁농협 하나로마트 직원 근무 관리 웹앱입니다. 서버 PC의 로컬 SQLite 파일에 직원, 계정, 근무표, 희망휴무를 저장합니다.

## 시작하기

Node.js가 설치된 서버 PC에서 실행합니다.

```sh
npm install
npm run build
npm start
```

브라우저에서 `http://localhost:3001`을 엽니다. 최초 관리자 계정은 서버 PC에서 한 번 설정합니다. 아이디는 영문/숫자 기준 3자 이상, 비밀번호는 10자 이상이어야 합니다. 직원 계정은 관리자 화면의 직원 관리에서 발급합니다.

## 휴대폰에서 접속

서버는 기본값으로 `0.0.0.0:3001`에서 요청을 받습니다. 서버 PC와 휴대폰이 같은 Tailscale 계정 또는 Tailnet에 연결되어 있으면, 휴대폰 브라우저에서 `http://<서버 PC의 Tailscale IP>:3001`을 엽니다. 공용 인터넷에 포트를 직접 열지 말고 Tailscale 안에서 사용하세요.

서버 PC에서 개발 화면을 직접 사용할 때는 `npm run dev`를 실행합니다. 화면 개발 서버는 Vite 기본 포트에서 열리고 `/api` 요청은 3001번 서버로 전달됩니다.

## 기능

- 관리자 최초 설정, 관리자/직원 로그인, 역할별 화면과 API 권한 분리
- 직원 추가·수정·삭제, 채용 구분, 재직 상태, 근무 조건 관리
- 직원별 아이디와 초기 비밀번호 발급 및 변경
- 직원별 희망휴무 신청, 관리자의 승인·반려
- 월간 오픈·마감·휴무 편집, 근무시간 표시, 인쇄
- 대한민국 공휴일과 주말 기준 휴무 계산, 임시 공휴일 추가
- 동시휴무 제한, 일별 정규직 오픈·마감 배치, 휴무일수 검증
- 조건이 충돌해도 자동 근무표를 생성하고 남은 확인 항목 안내
- 직원 화면에서는 채용 구분 정보를 API 응답이나 화면에 노출하지 않음
- 모바일 화면에서 날짜별 근무 일정을 읽고 희망휴무 신청

## 데이터와 백업

운영 데이터는 `data/shift-planner.sqlite`에 저장됩니다. 이 폴더는 공개 저장소에 포함되지 않습니다. 서버를 멈춘 뒤 `data` 폴더를 별도 안전한 위치에 복사해 백업하세요.

관리자 일정 화면의 수기 근무표 참고 이미지는 `data/reference-schedule.png`에 둘 수 있습니다. 계정이 있는 관리자에게만 제공되며 Git에는 포함되지 않습니다.

## 네트워크 참고

휴대폰 접속은 서버 PC가 켜져 있고 Node 서버가 실행 중이어야 합니다. Tailscale은 별도의 Wi-Fi 공유기 없이 모바일 데이터에서도 연결할 수 있지만, 휴대폰과 서버 PC가 같은 Tailnet에 로그인되어 있어야 합니다.
