# 왕궁농협 하나로마트 근무표

Vite, React, Express, SQLite로 만든 왕궁농협 하나로마트 직원 근무 관리 웹앱입니다. 서버 PC의 로컬 SQLite 파일에 직원, 계정, 근무표, 희망휴무를 저장합니다.

## 시작하기

Node.js가 설치된 서버 PC에서 실행합니다.

```sh
npm run app
```

`npm run app`은 첫 실행에 패키지를 준비하고, 화면을 빌드한 뒤 서버를 실행합니다. 터미널을 열어 프로젝트 폴더에서 실행하세요. 종료는 `Ctrl+C`입니다. 패키지 설치와 실행을 따로 하려면 `npm install`, `npm run build`, `npm start`를 사용할 수도 있습니다. Windows에서 npm을 인식하지 못하면 터미널을 다시 열고 `npm.cmd run app`을 실행하세요.

브라우저에서 `http://localhost:3001`을 엽니다. 최초 관리자 계정은 서버 PC에서 한 번 설정합니다. 아이디는 영문/숫자 기준 3자 이상, 비밀번호는 10자 이상이어야 합니다. 직원 계정은 관리자 화면의 직원 관리에서 발급합니다.

## 휴대폰에서 접속

서버는 기본값으로 `0.0.0.0:3001`에서 요청을 받습니다. 서버 PC와 휴대폰이 같은 Tailscale 계정 또는 Tailnet에 연결되어 있으면, 휴대폰 브라우저에서 `http://<서버 PC의 Tailscale IP>:3001`을 엽니다. 공용 인터넷에 포트를 직접 열지 말고 Tailscale 안에서 사용하세요.

서버 PC에서 개발 화면을 직접 사용할 때는 `npm run dev`를 실행합니다. 화면 개발 서버는 Vite 기본 포트에서 열리고 `/api` 요청은 3001번 서버로 전달됩니다.

## 기능

- 관리자 최초 설정, 관리자/직원 로그인, 역할별 화면과 API 권한 분리
- 직원 추가·수정·삭제, 채용 구분, 재직 상태, 근무 조건 관리
- 직원별 아이디와 초기 비밀번호 발급 및 변경
- 직원별 희망휴무 신청, 관리자의 승인·반려
- 월간 오픈·마감·휴무 편집, 근무시간 표시, 인쇄
- 대한민국 공휴일과 주말 기준 휴무 계산, 임시 공휴일 추가
- 동시휴무 제한, 일별 정규직 오픈·마감 배치, 휴무일수 검증
- 평일은 5명, 주말·공휴일은 4명을 목표로 편성하고, 불가능할 때도 평일 4명·주말/공휴일 3명을 우선 확보
- 매일 오픈·마감 배치를 가능한 한 균형 있게 나누며, 완화된 최소 인원에도 못 미치는 날짜만 확인 항목에 표시
- 직원별 가능한 근무(오픈·마감)와 매월 n번째 요일 정기휴무 설정
- 월별 기준 휴무일수를 지키고 주별로 고르게 배분
- 월별·주간 휴무, 동시휴무 제한, 정기휴무를 우선 지키는 자동편성
- 필수 휴무 때문에 정규직 오픈·마감 배치가 불가능하면 부족을 최소화하고 가능한 직원으로 편성한 뒤 날짜별 경고 표시
- 승인 신청을 우선하고 필수조건 안에서 희망휴무 반영을 최적화
- 전체 재편성과 기존 배정을 유지하는 빈칸 채우기
- 한국 시간 기준 지난 날짜의 근무를 고정하고 수동 수정·초기화·전체 재편성에서 보존
- 선택한 월의 근무만 안전하게 초기화하며, 초기화 전에 데이터베이스를 자동 백업
- 월·주간 휴무 등 필수 조건 충돌 시 기존 근무표 보존 및 원인 안내
- 서버에서 검증한 뒤 근무표 확정, 직원·근무조건 변경 시 확정 해제
- 참고 사진에서 입력한 근무 및 불확실한 내용 확인 목록
- 직원 화면에서는 채용 구분 정보를 API 응답이나 화면에 노출하지 않음
- 모바일 화면에서 날짜별 근무 일정을 읽고 희망휴무 신청

## 데이터와 백업

운영 데이터는 `data/shift-planner.sqlite`에 저장됩니다. 이 폴더는 공개 저장소에 포함되지 않습니다. 월 초기화 전 데이터베이스 백업은 `data/backups`에 저장됩니다. `data/backups/schedule-snapshots.json`에서 이름이 지정된 전체 DB 스냅샷을 확인할 수 있습니다. 초기화 때 지운 사진 근무표와 확인 메모는 `data/reference-import-history.json`에 보관합니다. 별도 안전한 백업으로 `data` 폴더 전체도 복사하세요.

관리자 일정 화면의 수기 근무표 참고 이미지는 `data/reference-schedule.png`에 둘 수 있습니다. 계정이 있는 관리자에게만 제공되며 Git에는 포함되지 않습니다.

최초 직원 명단을 지정하려면 서버 시작 전에 `data/initial-employees.json`에 직원별 `name`, `employmentType`, 선택적으로 `workRules`를 저장할 수 있습니다. 초기 설정은 `data/initial-settings.json`에 저장합니다. 이 파일들은 최초 빈 DB에만 적용하며 기존 운영 데이터를 덮어쓰지 않습니다. 직원의 특이사항 메모는 설명용이고, 실제 자동편성 조건은 직원 수정 화면의 **가능한 근무 / 정기휴무**에서 설정하세요.

월별 기준 휴무일수는 유지하고, 각 주의 해당 월 근무일수에 비례해 휴무가 몰리지 않도록 편성합니다. 정기휴무와 기존 수기 배정은 우선 반영합니다.

정규직 인원이나 필수 휴무 때문에 매일 정규직 오픈·마감을 채울 수 없는 달이 있습니다. 예를 들어 31일에 기준휴무 11일이면 정규직 3명의 총 근무는 60회지만 오픈·마감에 매일 한 명씩 필요하면 62회가 필요합니다. 시스템은 월·주간 휴무와 직원 규칙을 유지하면서 정규직 배치 부족 날짜를 최소화하고, 해당 근무 시간은 가능한 직원으로 편성해 경고합니다. 부족 날짜를 확인하고 나머지 필수조건을 충족하면 확정할 수 있습니다.

## 검증

`npm test`는 자동편성·주간 휴무·정기휴무·기존 배정 보존·확정 API·권한 검증을 수행합니다. API 테스트는 임시 DB를 사용하며 운영 데이터를 변경하지 않습니다. `npm run build`와 `npm run lint`로 화면 빌드와 정적 검사를 실행합니다.

## 네트워크 참고

휴대폰 접속은 서버 PC가 켜져 있고 Node 서버가 실행 중이어야 합니다. Tailscale은 별도의 Wi-Fi 공유기 없이 모바일 데이터에서도 연결할 수 있지만, 휴대폰과 서버 PC가 같은 Tailnet에 로그인되어 있어야 합니다.
